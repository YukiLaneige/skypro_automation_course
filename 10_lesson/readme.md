# Проект автоматизации тестирования (Урок 10): Slow Calculator и Saucedemo Shop

Данный проект содержит автотесты для веб-калькулятора с задержкой выполнения операций и интернет-магазина Saucedemo. Тесты построены по паттерну **PageObject**, содержат строгую типизацию аргументов/возвращаемых значений и полностью интегрированы с репортером **Allure**.

## 🚀 Предварительные требования

Перед началом работы убедитесь, что у вас установлены:
1. **Python 3.x**
2. **Браузеры и их драйверы**: Google Chrome (для тестов калькулятора) и Mozilla Firefox (для тестов магазина).
3. **Allure CLI** (утилита командной строки для работы с отчетами):
   * На Windows (через Scoop): `scoop install allure`
   * На macOS (через Homebrew): `brew install allure`

Установите необходимые Python-зависимости проекта:
```bash
pip install selenium pytest allure-pytest
```

## ⚙️ Запуск тестов и формирование отчета

Для запуска автотестов конкретно для 10-го урока из корня репозитория курса (`skypro_automation_cours`) и сбора результатов выполнения в директорию `allure-results`, выполните команду:

```bash
python -m pytest 10_lesson/ --alluredir allure-results
```

> **Важно:** Папка `allure-results` генерируется автоматически во время прогона тестов в корневом каталоге, откуда вы вызываете команду. Добавлять её в Git-репозиторий (делать `push`) не нужно.

## 📊 Просмотр сформированного отчета Allure

После успешного выполнения тестов вы можете сгенерировать и просмотреть интерактивный отчет в веб-интерфейсе браузера. Выберите один из двух способов:

### Способ 1: Быстрый просмотр через локальный веб-сервер (Рекомендуется)
Данная команда самостоятельно компилирует собранные лог-файлы во временный красивый HTML-отчет и мгновенно открывает его в новой вкладке браузера:
```bash
allure serve allure-results
```

### Способ 2: Статическая генерация HTML-отчета в каталог
Если вам необходимо сохранить готовый скомпилированный отчет в виде постоянной папки с файлами на диске (например, для передачи коллеги):
```bash
allure generate allure-results -o allure-report --clean
```
Чтобы просмотреть этот сгенерированный статический отчет из папки `allure-report`, запустите команду:
```bash
allure open allure-report
```

> **Примечание:** Создаваемую папку `allure-report` также следует исключить из отслеживания Git (добавить в `.gitignore`) и не отправлять на удаленный репозиторий.
