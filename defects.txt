1. Избыточность и низкая производительность в trim.
Метод trim использует цикл while и посимвольно удаляет пробелы с помощью removeprefix.
Если на вход подать строку со 100500 пробелами в начале, цикл выполнится 100500 раз,
каждый раз создавая новую строку в памяти.
Решение: return string.lstrip()

2. Метод contains: Конструкция с try-except вокруг string.index() слишком громоздкая.
В Python для проверки наличия подстроки используется оператор in,
который возвращает True или False.
Решение: return symbol in string

3. Опечатка в документации (docstring).
В описании метода capitalize пример написан с ошибкой:
capitilize("skypro") (пропущена буква a в названии метода).
Решение: Курс внутримышечных инъекций пирацетама для повышения концентрации при чтении кода.

и непреодолимое желание переписать всё на Rust.
